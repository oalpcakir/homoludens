HOW TO APPLY (GitHub Desktop)
1. In GitHub Desktop, make sure the homoludens repo has no uncommitted changes and is up to date (Fetch/Pull).
2. Unzip this archive and copy the "homoludens" folder's contents over your local clone
   (Documents\GitHub\homoludens), choosing "Replace the files in the destination".
3. Delete these 4 files by hand (old share images nothing uses any more, 3.4 MB):
     public\og-cupoftea.png
     public\og-kantar.png
     public\og-polder.png
     public\og-retourvloot.png
4. GitHub Desktop should now show about 135 changed files. Commit and push.
   The GitHub "Check" workflow rebuilds everything and runs all tests (about 15 minutes).

You can delete this text file before committing (or keep it; nothing reads it).

Store uploads (itch.io / CrazyGames) are not in the repo: build them with
   python3 build.py && python3 src/platform/build_platforms.py
or use the ZIPs that came with this update. Page text and settings: src/platform/STORES.md
